INSTALASI CEPAT
---------------
1. Install Node.js LTS dari https://nodejs.org/
2. Buka Command Prompt/PowerShell di folder ini
3. Jalankan: npm install
4. Jalankan: npm start             (untuk menjalankan langsung)
   ATAU
   Jalankan: npm run dist          (untuk membuat installer .exe)
5. Installer tersedia di folder dist/
